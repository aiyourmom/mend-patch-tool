mend is a command-line tool that applies AI-written edits in four formats — unified diffs (with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of files, atomically: every file or none. Node 22, standard library only.

## Run it

```sh
node main.ts [--format=unified|search-replace|v4a|json] [--check] [--strict] [PATCH]
```
